# Neodit
Готовый фронтенд для Supabase.

1. Если таблицы уже удалены — запусти `supabase.sql` в Supabase SQL Editor.
2. В Supabase Authentication → Providers → Email отключи Confirm email, если хочешь регистрацию без подтверждения почты.
3. Загрузи `index.html`, `style.css`, `app.js` на GitHub Pages.
4. Не добавляй service_role/secret key в браузер.

Регистрация: юзернейм + пароль.
